# Proyek Klasifikasi Gambar: Fresh and Stale Classification

Model Deep Learning ini dibangun menggunakan Convolutional Neural Network (CNN) untuk mengklasifikasikan gambar buah segar dan busuk ke dalam 6 kelas:
`freshapples`, `rottenapples`, `freshbanana`, `rottenbanana`, `freshoranges`, `rottenoranges`.

Akurasi Model ini pada Test Set: **98.80%** dan pada Training Set: **97.05**
